# 🌤️ Philippines Weather API

A RESTful API built with **Laravel** that provides a list of Philippine cities and retrieves real-time weather information for a selected city.

This API serves as the backend for the Vue.js Weather App and acts as a bridge between the frontend and an external weather service.

---

## ✨ Features

- 🇵🇭 Retrieve Philippine cities
- 🔍 Search cities
- 🌦️ Get current weather by city
- 🌡️ Temperature
- 💧 Humidity
- 🌬️ Wind speed
- ☁️ Weather description
- 📦 RESTful JSON responses
- ⚡ Fast and lightweight API

---

## 🛠️ Tech Stack

- Laravel 12
- PHP 8.2+
- MySQL
- Eloquent ORM
- Laravel HTTP Client
- External Weather API
